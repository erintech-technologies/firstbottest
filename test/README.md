# فروشگاه تستی تلگرام

ربات فارسی فروش محصولات دیجیتال با aiogram 3، SQLAlchemy 2 و فایل SQLite محلی.

## اجرا در Windows

1. Python 3.11 تا 3.14 را نصب کنید. نسخه‌های جدید aiogram فعلاً Python 3.15 را پشتیبانی نمی‌کنند؛ اگر روی این سیستم فقط Python 3.15 دارید، نسخه aiogram انتخاب‌شده در requirements ممکن است نصب نشود.
2. در پوشه پروژه محیط مجازی بسازید و فعال کنید:

        py -m venv .venv
        .venv\Scripts\Activate.ps1
        python -m pip install -r requirements.txt
        Copy-Item .env.example .env
        code .env

3. در فایل .env مقدار BOT_TOKEN را از BotFather وارد کنید. شناسه مدیر، کانال عمومی عضویت اجباری و نام فروشگاه نیز قابل تنظیم هستند. برای بررسی عضویت قابل اتکا، ربات را در کانال مدیر کنید.
4. در پوشه اصلی اجرا کنید:

        python -m app.main

برای توقف Ctrl+C را بزنید. فایل پایگاه داده در data/shop.db ساخته می‌شود. فایل .env وارد Git نمی‌شود.

## گردش کار اولیه

- مدیر اصلی با شناسه پیش‌فرض 137217869 پس از /start دکمه مدیریت را می‌بیند.
- از مدیریت، دسته‌بندی و محصول بسازید؛ سپس موجودی دیجیتال را با یک کد/محتوا در هر خط اضافه کنید.
- کاربر محصولات را می‌بیند، محصول را به سبد می‌افزاید و با موجودی کیف پول خرید می‌کند.
- درخواست افزایش موجودی، مبلغ و تصویر رسید را ثبت و برای مدیر ارسال می‌کند. مدیر دکمه تأیید یا رد را می‌زند.
- دستور /cancel مراحل ورودی را لغو می‌کند.

## محدودیت‌های نسخه فعلی

این نسخه برای آزمایش اولیه است. پرداخت مستقیم بانکی/درگاه وصل نیست؛ رسیدها دستی بررسی می‌شوند. سبد خرید فعلاً هر محصول را یک‌بار می‌پذیرد. مدیریت مدیران فرعی و مجوزها، ویرایش/حذف دسته و محصول، کد تخفیف، پیام همگانی، پشتیبانی، متن‌های قابل ویرایش، مدیریت کامل سفارش‌ها، FSM پایدار و مهاجرت دیتابیس هنوز پیاده‌سازی نشده‌اند. خرید با کیف پول و موجودی برای یک اجرای آزمایشی تک‌نمونه‌ای است و کنترل تراکنش هم‌زمان چند نمونه ربات تقویت نشده است. برای راه‌اندازی واقعی، بررسی امنیتی و آزمون پرداخت لازم است.

## ران کردن روی سرور

برای سرور لینوکس، داخل پوشهٔ پروژه این دستورات را اجرا کن:
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env

python -m app.main


برای اجرای مداوم روی سرور، می‌توانی از systemd یا tmux استفاده کنی. فایل پایگاه‌داده به‌صورت پیش‌فرض در data/shop.db ساخته می‌شود.
